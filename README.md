## Current status and boundary

**Status:** `CURRENT`

This repository is the public-facing organization profile and shared public community-default surface. It intentionally exposes product categories and public context only. It does not own private homelab truth, product implementation, internal roadmaps, secrets or runtime data.

The Portfolio Office repository register remains the classification authority. Private operational details belong in the appropriate private repositories.

## Recovery and usage

1. Read this gateway and verify the accepted `main` branch.
2. Treat the sections below as public navigation, not implementation authority.
3. Follow each product’s public repository/site link for published information.
4. Make profile-only changes through issue/branch/PR and verify links with `git diff --check`.

There is no runtime, build, deployment or package release in this repository.

## Version, release and safety

**Version policy:** `internal/unversioned`; the accepted commit SHA identifies a profile revision.

**Release model:** `none`. A merge changes public organization presentation only; it does not publish product artifacts or authorize private operations.

Never publish secrets, personal data, private network addresses, credentials, internal recovery details or unverified product claims here.
